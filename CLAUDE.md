# CLAUDE.md - Application Topo (site PC + APK Android + Topo Tablette + Topo Bureau, usage personnel)

## Utilisateur et manière de travailler
- Géomètre topo suisse, **débutant en développement**. Répondre **en français**, simplement, sans jargon (définir un terme technique en une phrase).
- Poser **toujours** des questions **avant** une décision importante ou ambiguë. Ne **jamais deviner** une formule ou une norme de topo : le dire et faire valider.
- Fonctionnalité : lancer les tests, expliquer, dire comment l'essayer, proposer la suite.
- Nouvelle fonctionnalité : **toujours demander** dans quel mode la mettre (**Base**, **Intermédiaire** ou **Expert**) avant de la coder.
- Tout se fait dans le cloud ; l'utilisateur n'utilise que navigateur / tablette.
- **Tablettes Android toujours en portrait** (décidé le 13.11) : tester et dessiner en portrait (tablette 8" simulée à 800 × 1280 ; téléphone < 500 px). Paysage non prioritaire.
- **Quatre façons d'utiliser Topo (décision du 22.11), même appli web, même numéro de version** : **site PC** (navigateur, se connecter de n'importe où) ; **APK Android** (tablettes terrain) ; **Topo Tablette** (`TopoTablette.exe`, l'ancien `Topo.exe` renommé le 22.11 : tablette terrain Windows CC180) ; **Topo Bureau** (`TopoBureau.exe`, 0.277.0 : le PC du bureau, la même chose que le site PC mais installée, avec des fonctions avancées : DWG par ODA File Converter (installé sur le PC de l'utilisateur), calage de plans…). Topo Bureau = même code C# que Topo Tablette (`windows/TopoBureau/TopoBureau.csproj` compile `windows/Topo/*.cs` avec la constante `BUREAU`, voir `Edition.cs`).
- **Windows (14.11)** : on garde APK Android **et** `Topo.exe`. Toute modification se fait et s'essaie **d'abord pour l'APK**. **18.11 : Android et Windows gardent le même numéro de version** : `windows.yml` refait Topo.exe tout seul à chaque changement de `package.json` (donc à chaque nouvelle version). La tablette Windows (CC180) est **en paysage** (1280 × 800 simulé).
- **Git** : commit en français après chaque fonctionnalité qui marche. Ne jamais demander mot de passe ni jeton dans le chat. Aucun identifiant de modèle dans commits / PR.
- Avant d'ajouter une bibliothèque : dire ce qu'elle fait, pourquoi, demander l'accord.

## Stack
- JavaScript vanilla (modules ES), **Vite 8**, **vite-plugin-pwa**, **Vitest 5** ; plan en SVG (fond DXF en canvas).
- Bibliothèques : `delaunator` + `@kninnug/constrainautor` (triangulation), `jspdf` (PDF), `pdf-lib` 1.17.1 (rapport du comparateur de PDF, accord du 22.11, chargé au 1er rapport), `heic-to` (photos HEIC), `pdfjs-dist` 6.4.299 (plans PDF, version legacy, accord du 05.11), `web-ifc` 0.0.78 (maquettes IFC, accord du 17.11 ; ~5 Mo chargés seulement au 1er import IFC, gardés hors ligne : cache `lecture-ifc`).
- APK Android : Kotlin sans bibliothèque (sauf `play-services-auth`), WebView ; la même appli web sert l'APK.
- Appli Windows : C# .NET Framework 4.8, WinForms, une seule bibliothèque `Microsoft.Web.WebView2` 1.0.2903.40 (accord du 14.11) ; la même appli web sert le `.exe`.
- Hébergement : GitHub Pages (`publier.yml`) ; APK par `apk.yml` (release `apk-derniere-version`). Partage de projets : Google Drive (`drive.file`).

## Conventions de code
- **Découpage de `main.js`** : petit à petit, au fil des demandes (jamais en gros) ; même comportement, avec tests et essai Playwright.
- Code et commentaires **simples, en français**. Une fonction de calcul = courte, commentée (rôle, unités), **avec un test**, dans `src/topo/`.
- Coordonnées **Est, Nord, altitude** (LandXML : Nord, Est, altitude), tout en **MN95**, mètres ; aucune conversion dans l'appli web (l'APK convertit GNSS et GPS tablette en MN95 / RAN95). Nombres : point décimal, 3 décimales, jamais « -0.000 » (`fixe3`).
- Messages d'erreur compréhensibles, jamais d'échec silencieux. Pas de phrases d'explication dans les écrans : l'aide est dans les bulles (`textes.js`, apostrophes `\'`).
- Texte venant de l'extérieur (noms d'appareils, fichiers, points) toujours passé par `echapper()`.
- **Préfixes fixes** (impossibles à modifier : `demanderTexte({ prefixe })`, `sansPrefixe`, `.champ-prefixe`, `prefixerNoms` à chaque modification et ouverture) : **`LV-`** levé (stock, terrain, libre, chantier), **`Surf-`** surface (importée ou de Dessin), **`PDF-`** plan PDF (`PREFIXE_PDF`), **`Imp-`** liste de points importée (`PREFIXE_IMPORT`, sans extension). `LV-` est réservé aux noms de listes (les boutons de nature disent « Levé stock »…). Surfaces importées sans nature : utilisables comme stock ou terrain.
- Noms de points jamais interprétés. Noms levés : contour `C-Stock-n-m`, ligne `L-lib-n-m`, point `P-lib-n`, aire `A-lib-n-m` ; sommets de dessin `D1-1`.
- Dans l'appli on écrit **GNSS**, jamais « RX2 » (sauf l'ancien nom de liste « Levé RX2 date »).
- Données sur l'appareil (IndexedDB) ; seule exception : Drive. Mot de passe NTRIP jamais dans le projet (sauf liste partagée swipos sur Drive, acceptée).
- Réglages de l'appareil (hors projet) : `topo-affichage`, `topo-sous-dossier`, `topo-colonnes-points`, `topo-export-plan`, `topo-reglages` (téléphone, mode, `tailleFormes`, `tailleTexte` : 4 tailles ; `theme` : `normal` / `sombre`), `topo-terrain`, `topo-plan-terrain-part`, `topo-plan-guidage-part`, `topo-favoris-applis`, `topo-ordre-applis`, `topo-applis-masquees`, `topo-coupe-ifc` (altitude de coupe des IFC, par projet), `topo-materiel-noms` (articles et responsables du parc pour Réglages › Drive), `topo-materiel-drive` (état de la copie Drive du parc). `topo-appareil` a aussi `article` (n° du parc de la tablette, 0.274.0).
- Fichiers exportés : un seul modèle **`affaire_contenu_date`** (`outils/nom-fichier.js`).
- Icônes dessinées (`outils/icones.js`, `ICONES_LIGNE`, `.ico-ligne`) à la place des émojis ; signes de texte ✓ ⚠ ✎ ✕ ⚙ ★ gardés.
- Pas de bouton « Annuler » visible : ne pas promettre d'annulation (Mesure rapide : « ↶ Retirer »).
- **Sticky** : ne jamais mettre `overflow-x: hidden` sur `html, body` (casse l'en-tête fixe) : `overflow-x: clip`.

## Modes : Base, Intermédiaire, Expert
- Réglages ⚙ ; logo = **pyramide** (vert / jaune / pointe rouge) ; **Intermédiaire par défaut** ; l'ancien « Confirmé » = Expert. Rien n'est supprimé du projet en changeant de mode. Règle : Base ⇒ Intermédiaire ⇒ Expert.
- Tableau de référence : `docs/modes-base-intermediaire-expert.xlsx` (remis à jour le 16.11, **à relire avant de coder**).
- Code (`reglages/reglages.js`) : `modeAppli()`, `aAcces('intermediaire' | 'expert')`, `estModeBase()`, `lameActive()` (= Expert) ; HTML : classes `.seulement-intermediaire` / `.seulement-expert` ; calques du plan : propriété `niveau`. **Nouvelle fonction : demander le mode, puis poser la classe ou `aAcces`.**
- **Base** : ouvrir un projet, carte des projets, Drive, **Lever = seulement le Levé chantier**, implanter point / ligne / surface (sans « Enregistrer l'implantation », coupes dans l'axe), Contrôle, récepteur, GPS tablette, plan (fonds, plans DXF, « Afficher »), liste de points, plans (état visible), archives (sans supprimer), export du contrôle, « Enregistrer » de la fenêtre Exporter.
- **Intermédiaire** en plus : créer un projet, toutes les natures de levé (Stock, Terrain, Terrassement, Libre), lignes / contours, libellés, Annotation, Mesure rapide, Delta, mesure de durée, accroches Manuel et Centre pts, « Enregistrer l'implantation », liste « À implanter » (coches), Calculs (volumes), exports PDF / DXF / mail, couleurs et exports de listes, supprimer un point (×), archiver, contrôler / recaler un plan, masquer / geler / isoler des calques, listes partagées, réglage swipos.
- **Expert** en plus : Plateformes (0.300.0, site + Topo Bureau), bloc Importer (points, plans DXF / PDF, maquette IFC (0.262.0 ; voir la coupe IFC : tous les modes), surfaces, Swisstopo, cadastre, avertissements d'import), exporter / dupliquer / supprimer un projet, Surface Projet, export CSV / LandXML, « Quoi exporter ? », prendre la main, talus, créer des « À implanter », coupes, Dessin / DAO, **Guidage** et 2e GNSS, **Réseaux**, réglages NTRIP, journal NMEA, supprimer un levé, calque Triangles, recalage par axes, vraie suppression (archives).
- Mode des nouveautés décidé le 16.11 : liste d'implantation avec coches = Intermédiaire ; noms cachés de loin = tous ; « Contrôler » un plan = Intermédiaire (état visible dès Base) ; avertissements d'import = Expert.
- **Code de sécurité** (`outils/code.js`, simple barrière, ne jamais l'écrire dans les bulles) : passer en Expert, nom de l'appareil, réglages NTRIP, roue ⚙ de Contrôle, prendre la main, listes partagées. Import de points de contrôle : sans code. « Relancer NTRIP » : sans code.
