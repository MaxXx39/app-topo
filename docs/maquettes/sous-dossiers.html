Sous-dossiers de projet : maquettes

Idée : dans un projet, des dossiers (Terrassement, Canalo, Bâtiment…). Le menu du projet permet de choisir Tout ou un dossier ; dans les applications, on ne voit alors que ce que l'Expert y a rangé. Format : tablette en portrait. Rien n'est codé : choisis ta variante pour chaque écran, puis on code.

Règles proposées (à valider)
  • Un élément (levé, liste de points, plan DXF / PDF, surface importée, réseau, dessin) est dans un seul dossier ou dans « Sans dossier ».
  • Tout montre tout, comme aujourd'hui. Les projets existants restent identiques (aucun dossier au départ).
  • Voir / choisir un dossier : tous les modes. Créer, ranger, déplacer : Expert.
  • Ce qui est créé (levé, import) va dans le dossier choisi à ce moment-là ; sous « Tout », il reste « Sans dossier ».
  • Le dossier choisi est un réglage de chaque tablette (comme « Afficher »). Le rangement, lui, est dans le projet (partagé par Drive).

Écran 1 : choisir le dossier dans le menu du projet

Page Applications, encadré or du projet. Les listes en dessous (Liste de points, Plans, Surfaces…) et les applications ne montrent que le dossier choisi.

Écran 2 : ranger à l'import

Les imports (points, plans DXF / PDF, surfaces) proposent le dossier, avec création si besoin. Expert seulement (l'import est déjà Expert).

Écran 3 : déplacer / ranger des levés et listes existants

Page « Gérer » du projet (Liste de points, Plans, Surfaces importées…). Expert seulement.

Questions pour toi

  1. Écran 1 : A (puces) ou B (liste) ? Combien de dossiers penses-tu avoir au maximum par projet ?
  2. Écran 2 : A (choix dans la fenêtre d'import) ou B (on range après) ?
  3. Écran 3 : A (un par un), B (plusieurs d'un coup), ou les deux ?
  4. Un élément dans un seul dossier suffit-il ? (Un plan utile à Canalo et à Terrassement devrait alors rester « Sans dossier » ou être importé deux fois.)
  5. Les applications (Lever, Implanter, Contrôle…) doivent-elles aussi respecter le dossier choisi, ou seulement les listes et le plan ?
  6. Noms des dossiers : libres (tu les crées) ou une liste de départ Terrassement / Canalo / Bâtiment ?
